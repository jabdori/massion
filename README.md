# Massion

Massion is a clean rebuild in the design stage. This repository starts with independent Git history; implementation has not begun.

The product direction is to turn a Mission into organized, durable Work: an organization carries the work forward, independent verification checks its outcomes, Records retain decisions and evidence, and Growth uses those records to improve future work.

**Mission → organization → durable Work → independent verification → Records → Growth**

Current work is defining product requirements, boundaries, and acceptance criteria. Architecture and implementation choices remain open.

## Historical implementation

The earlier implementation and its Git history are preserved in [massion-archive](https://github.com/jabdori/massion-archive). That repository is a historical archive; this repository is the starting point for the clean rebuild.
