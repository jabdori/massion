# Explicit literal-content memory retrieval

Selected product increment above Draft PR72 `22cbf56fdc9dee29c7e650679588008079014e34`: MEM-01 general retrieval, ADR0001 authoritative original bindings, issue #4 inspectable original inputs and issue #19 explicit versus learned data. ID discovery requires knowing the ID. This increment finds original explicit versions by an owner-entered literal content fragment when the ID is unknown, then chooses the exact reference for separate existing usage inspection. No ranking, semantic search, inferred applicability or automatic adoption.

GET `/missions/:id/memory-search?text=...&revision=...` requires original feed header and positive Mission revision; optional `after` is a positive multiple of 20. Fragment is nonblank well-formed Unicode, 1–512 UTF-16 units, retained without trimming/case folding/normalization. Literal case-sensitive `content.includes(text)` matches only same-Mission/scope explicit versions, including inactive originals; ID/source matches alone do not count. One readState validates original Work/Record lineage and feed/revision. Retained insertion order defines bounded 20-result pages with original memory ID/version/hash/source/content, total/offset/nextAfter. Missing fragment match is 200 empty; stale boundaries reject, invalid/out-of-range continuation rejects; no stored cursor or write.

Normal UI uses quoted JSON-string input to preserve CR/LF despite textarea normalization. One explicit Search/Next click makes one GET, no automatic fetch. Validate original versions/hashes/page against current snapshot. Explicit choice transfers the exact version to usage reader without querying it or applying memory; changing usage selection or choosing in either discovery panel invalidates the other selection's result/held response. Input/Cancel/Mission/feed/revision/offline/reconnect discard results. Restart starts no search. Existing Work/Record/unknown receipt/journal and write barriers remain unchanged.

Acceptance: 22 matching versions across multiple literal IDs read as 20 + 2, no duplicate/omission; original inactive selection flows to separate explicit usage read; learned/other-Mission/ID-only/source-only excluded. Case, spaces, CRLF/LF, Unicode NFC/NFD, 512/513 bounds, missing/invalid/extra/duplicate queries, tampered lineage/hash/pages, frozen caller input, stale peer/late/cancel/selection/feed replies. Actual DB, normal CLI/owned restart/headless keyboard/narrow view, separate local/CI skips, independent exact-head review, small Draft and issue backlink. Zero writes/model/provider calls; no credentials, grants, paid resources, merge/deploy. Preserve original dirty work and failure logs. This is bounded literal retrieval, not completion of MEM-01 or live judgment.
