# Owner-selected local UTF-8 file → document draft

KNW-01 still names document/code ingestion as independent product work. Existing local source capture requires manual paste; accepted ADR0001 requires explicit provenance and preserves prior source/Work/Record versions. Above PR59, let the owner choose one local file in the browser, inspect its literal filename/UTF-8 text and raw-byte hash, then deliberately replace private document content/source. Saving remains the existing separate exact document command.

This adopts a bounded local ingestion contract. The browser reads only the owner-selected File; the server gains no filesystem path access. At most16KiB raw bytes, strict UTF-8, nonblank text and no NUL; no URL fetch, archive, binary/PDF parser, code execution or model interpretation. Preserve UTF-8 BOM in text; explicitly normalize CRLF/CR to LF for the textarea, reporting raw-file and normalized draft hashes separately. Provenance is an owner/client claim in the existing source string, not host verification of an external file; Document content SHA-256 still seals the actual saved text. If the owner edits after import, existing literal source and final text remain reviewable; file hash is never relabeled final edited-content proof.

Acceptance before implementation: select → private preview → explicit use → editable document draft → deliberately review current ID/version/revision → separate save; original Work/documents/Records unchanged. File preview/Cancel/write0, effect/model0. Invalid/oversized files do not replace earlier private fields or send requests. Late file reads after new selection/private edits/Cancel/Mission/feed/reconnect/state changes cannot install or overwrite a draft. Current pending/unknown barriers remain; no source save/retry/attachment or execution is automatic. Raw and LF-normalized hashes, literal hostile-looking filename/content, exact existing save/receipt/CAS semantics, real DB/normal CLI/native headless keyboard and narrow layout, independent review and exact-head CI are separate evidence. General ingestion/indexing/parser/graph semantics remain open.
