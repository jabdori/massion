# User proposals and host-owned bounded evaluation

The local owner can propose a scoped memory improvement through `ProductService.proposeGrowth` or `POST /missions/:id/growth-proposals`. Input is commandId, expectedRevision, growthId, exact effective baseline (`memory@version`), candidate `{id,version,content,source}` and counterevidence. The existing representative transition atomically stores the candidate as inactive learned memory and the proposal as proposed. The local owner is recorded as proposer; this route does not grant arbitrary caller roles or turn a proposal into effective memory. Wrong baseline, duplicate/nonadvancing version, absent provenance/limitations or unsupported extra fields fail without a partial candidate write. Source is owner-supplied provenance, not authenticated external truth.

`ProductService.evaluateGrowth` or `POST /missions/:id/growth-evaluation` accepts only commandId, expectedRevision, growthId, exact baseline/candidate, oracle and input cases. The host selects its own evaluator `host-rounding-oracle/v1`; evaluator, score, pass, heldOut or executable code from the caller are rejected. Only `rounding-calculation/v1` is enabled. Memory instructions must exactly equal “Round each line” or “Round aggregate once”. Other text, targets and oracles remain unsupported; a stored text proposal is not necessarily executable by this evaluator.

Cases are caller-authored orders `{items:[{unitPriceCents,quantity}],discountBasisPoints}`. There are 1–32 cases, at most 16 items per case, integer prices0–1000000, quantities1–1000, discount0–10000 and subtotal at most1000000000. Nested extra fields, expected values and scores are rejected. Stored evaluation evidence is bounded to16000 UTF-8 bytes; larger evidence requires fewer input orders. This oracle assumes an order-level discount, aggregated once and rounded half-up in integer cents. It cannot assess legal/tax per-line rules or arbitrary natural-language instructions.

The host computes expectations using exact integer arithmetic and runs only trusted policy calculation code in a separate bounded Node process with empty environment, fixed argv, Node permissions, timeout/output limits and no user code. Only a process report matching the exact planned outputs permits an evaluator-owned domain commit. Process failure records no successful evaluation. Node permissions are defense in depth, not OS isolation.

Evidence retains oracle/code hash, input orders/hash, exact memory version/content/source hashes, observed results and scores. These are the caller's cases, not a secret held-out set or model-learning certificate. Canonical deterministic evidence gives stable command identity. Version hashes exclude mutable `effective` state; current scope/effective flags are checked separately for new admission and again in the atomic domain transition. Exact replay after adoption returns the original durable receipt, even though effective flags changed. Changed request data with the same command identity conflicts. Receipt lookup happens before another process evaluation; original CAS protects the final asynchronous commit.

The normal Workbench includes private per-Mission proposal drafts, source/counterevidence and explicit current-revision review. Select the exact proposed Growth and enter input orders to evaluate. Existing adopt/revert, durable receipt/unknown barriers and later-Work pins are reused. A proposal or evaluation never changes old Work/Record pins. Adoption requires measured improvement; reevaluation of another dataset is not silently substituted after acceptance. On lost response inspect durable receipt/current state; no browser POST replay or automatic proposal/evaluation/adoption occurs.

This loopback development host has local owner identity, not production multi-device authentication. No model, credentials, external evaluator service, paid resource or new account permission is used. Automatic mode, arbitrary model learning, general proposals/evaluators, prompt/policy/organization Growth targets and production organization revisions remain open.
