# Bounded local host drain

RUN-01/WRK-01/EFF-01 above PR45 `063b2f8`: normal CLI SIGINT/SIGTERM enters one idempotent bounded drain. This synchronously rejects new HTTP mutations and forwards beginDrain through existing connection/router layers to exact locally owned bounded-text runtime controllers. Runtime activation is fenced immediately before underlying Store commit invocation after asynchronous Application reads. Already invoked transactions may still finish; newly registered controllers observe draining before progression. Existing deadline/abort progression fences remain. Runtime promises are tracked from entry and awaited independently of HTTP sockets, so closing a UI response socket cannot make shutdown appear clean before owned runs settle. Activation ACK loss reads exact original host/dispatch and closes it without dispatching; unavailable original readback reports unknown/unsettled.

`stop-owned-runtime` is an internal representative closure, never an owner HTTP command. It binds original run/dispatch/host session and an actual observed time at or after original admission. Imported interruption shape retains original local cause (`host-shutdown` versus `deadline`) and unknown effect IDs. Pending intents/claims become receipt-free unknown; existing unknown receipts, reservations and unknown usage are retained. Accepted Records and older unowned Work remain unchanged. Local cancellation of an already invoked adapter does not prove that remote execution stopped or authorize retry, lease reclaim or replay. A future host may inspect originals only.

Normal server drain waits for HTTP closure within10seconds (host-provided test option at most30seconds). Socket timeout or admitted-run durable closure failure reports `unsettled`; normal CLI exits nonzero. This does not force remote models or guarantee completion of already invoked storage transactions. SIGKILL cannot drain. No endpoint grants new shutdown/model authority, no automatic startup recovery, no production daemon supervisor/installer/OS isolation or general scheduler/recovery completion.

[Acceptance evidence](../acceptance/host-drain-evidence.md) distinguishes controlled adapters and actual owned CLI signals from real model usefulness.
