# Explicit original source input for Work

The owner can attach an exact retained document ID, version and SHA-256 to a fresh unstarted Work through `POST /missions/:id/work-source` and the Workbench source panel. This closes the inspection-only gap after [document capture](owner-documents.md): a selected original can become a reproducible execution input without manually copying it into owner instructions.

This implements the bounded WRK-01/ASR-01/REC-01/KNW-01 path in [requirements](../product/requirements.md) and ADR0001's product-owned fixed input/evidence/version responsibilities. It does not add automatic retrieval, latest-version selection, ingestion, relationships, invalidation, permission or truth assertions.

The command fields are `commandId`, `expectedRevision`, `workId`, `documentId`, `version`, `contentSha256`, `reason`. The host binds the local owner, validates the retained original and copies its complete text/title/source/hash/author into `Work.sourceDocuments` with the selection author/reason. The original journal command remains separately retained. Up to three distinct document IDs and 64KiB of canonical serialized source input are allowed. No source replacement/removal is exposed; a correction uses a new Work. Source selection is available only while acceptance is pending, no run/recovery/evidence exists, and the single original task/attempt has no progress. Attachment does not execute Work.

`workInputHash` includes explicit source pins, while Work without that optional field retains its previous hash contract. Preflight and runtime activation validate the original full snapshots against retained history. Both executor and independent verifier receive `sourceDocuments` as untrusted JSON reference data. The source-bearing built-in text extension is version `@4`; legacy contracts retain their version. Prompts explicitly prohibit treating document commands as host instructions or permissions. This framing is not proof of real-model prompt-injection resistance.

Acceptance includes the original source pins in the canonical Record checksum. Exact accepted-text reads check Work/Record/original equality before and after artifact reading. Portable lineage checks optional fields, original source pins, Record equality and semantic replay of the original owner decisions. Missing or altered originals fail closed; no newer source substitutes for them.

The panel retains exact private source selection, original comparison, reason, feed and aggregate revision. State changes require an explicit review before a new command. CAS rejection retains the draft without retry. Pending/unknown outcomes lock writes; only durable receipt/event recovery clears the lock. Reload stores only operation identity, never source text/reason. Original source and Work details render as literal text. The existing document read panel remains the hash-checked read path.
