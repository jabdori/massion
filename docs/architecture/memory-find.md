# Explicit literal-ID memory version discovery

Approved follow-up above Draft PR71 `ffb19e4b6794f932c52451a23e7d54bae58b5878`, for MEM-01 general retrieval, ADR0001 authoritative read/original binding and issue #4 original input inspection. Usage pages inspect uses of an already chosen version; this increment finds the stored explicit versions for one original literal ID in the selected Mission before that choice. No ranking, inferred relevance, content query or automatic application.

GET `/missions/:id/memory-versions?id=...&revision=...` requires original feed header and positive Mission revision. Optional `after` is a positive multiple of 20. One readState validates original Mission/Work/Record lineage, exact feed/revision, and returns only explicit same-scope versions whose ID equals the input without trimming/normalization. Preserve original stored order, immutable ID/version/hash, current effective and historical source/content. At most 20 results, total/offset/nextAfter; a missing ID is 200 with zero results, missing Mission is 404. Stale feed/revision rejects; invalid/out-of-range continuation rejects, no newer state fallback or stored cursor.

Normal UI accepts the ID as a quoted JSON string so CR/LF and Unicode survive HTML textarea line-ending normalization. Parse once without altering the decoded ID; enforce the existing nonblank/well-formed/16,000 UTF-16-unit identity boundary. Each explicit Find/Next click issues one GET. Validate returned original version hashes and bounded page against the current snapshot. An explicit result choice transfers only exact ID/version/hash to the existing usage reader, without querying usage or applying memory. Cancel/input/selection/Mission/feed/revision/reconnect changes invalidate held or completed results; fresh browser/restart reads nothing automatically. Existing unknown-write locks and all Work/Record/journal stay untouched.

Acceptance: 22 explicit versions read as 20 + 2 without omissions/duplicates; inactive originals and old Work/Record/unknown pins retained; near LF/CRLF, whitespace, NFC/NFD IDs distinct; other Mission/learned excluded, missing ID empty. Reject malformed/duplicate/extra queries, wrong feed/revision, corrupted lineage, forged pages and late response; bounded keyboard/narrow browser selection to usage, normal CLI/owned host restart, zero writes/provider/model calls. Preserve reproduction failures, local actual DB/Chrome and remote CI skips separately, independent exact-head review and Draft/issue backlink.
