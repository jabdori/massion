# Explicit exact-memory usage pages

Approved MEM-01 follow-up above Draft #70 `8a2ecef603e6de89fab6a96e39b5d2f2cf9fc843`, linked to ADR0001 and open issue #4 historical input inspection. Existing exact ID/version/hash reads report the total but return only the first 20 Work/Record uses. Add explicit continuation with the same 20-use bound; no search/ranking or new authority.

Normal GET `/missions/:id/memory-usage` retains required id/version/hash and optional feed. New optional `revision` binds the Mission snapshot. Continuation `after` is a positive safe integer multiple of 20 and requires the original feed header and positive original revision. One authoritative readState must match feed and Mission revision before returning any continuation; changed state rejects with 409, never a substituted newer page. ID/version/hash and validated original Work/Record lineage remain exact. Work insertion order in the frozen revision defines ordinal pages. Reply includes `offset`, `nextAfter` (null at end), exact total, revision/feed/cursor and at most 20 uses. Global event cursor is informational; another Mission changing it does not mix the selected Mission's unchanged revision. Invalid or out-of-range continuation rejects. No stored cursor, write or command.

UI adds explicit Read next 20 uses. It retains the original reference/feed/revision, displays only the current bounded page and its ordinal range, and sends one GET per explicit initial/next click. It does not fetch/append pages automatically. Cancel/selection/Mission/revision/feed/reconnect changes clear the page boundary; held replies cannot populate a different selection/state. Duplicate in-flight clicks send no extra read. Error retains no continuation authorization and requires an explicit initial read. Restart/fresh browser performs no automatic usage read. Exact response original hash, total/order/page metadata and retained Work/Record values are checked against the selected snapshot. No hidden trimming/normalization or latest-version fallback.

Acceptance: 22 original uses → initial 20 + explicit final 2, no duplicates/omissions, exact original ID/version/hash and old Work/Record/unknown effects. Boundaries 0/1/20/21/22/40, malformed/missing continuation context, wrong feed/hash/revision, concurrent state changes, frozen caller inputs, tampered lineage; late replies after Cancel/selection/Mission/revision/feed changes and forged page metadata. Real DB, normal CLI/headless keyboard/restart, local versus CI/browser skips, independent review, small Draft/exact-head CI and reciprocal issue checkpoint. Reads/Cancel are GET-only with zero writes/provider/model/live calls. Preserve original dirty work/evidence. No model call, execution grants, merge/deploy, paid resources or account changes.
