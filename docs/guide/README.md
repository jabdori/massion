# Massion development guide

Massion keeps a continuing conversation and follows delegated work through an
independent check to a retained result. This guide is for the owner trying the
current development build on a private machine.

This is an unsigned development candidate, not a production release. Some planned
capabilities have no usable execution path yet. The examples and screenshots in
the regression suite use local fixtures; they do not demonstrate model quality.
The current interface is in Korean; this guide explains it in English.
